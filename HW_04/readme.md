 **База данных** — глобальный связный список (`g_records`), хранящий записи типа `record_db_t`.
 ```c
 typedef struct record_db {
	char *name;
	long id;
	struct list_head node;
} record_db_t;
 ```
  `record_db_t`   фактически это строка в базе
- Каждая запись содержит:
  - `id` (уникальный числовой идентификатор, от 100 до 999),
  - `name` (строка из предопределённого списка имён).
- Список **отсортирован по возрастанию `id`** для ускорения поиска.

ри загрузке модуля создаются:
- **`readers` потоков-читателей** — каждый случайным образом ищет запись по `id`.
- **`writers` потоков-писателей** — каждый:
  - либо **изменяет имя** существующей записи,
  - либо **добавляет новую запись**, если `id` не найден.

Все потоки работают в цикле до получения сигнала остановки (при выгрузке модуля). В юзерспейс приложении завершаются самостоятельно, как только каждый
читатель или писатель находит запись.

###  **Параметры модуля (можно задать при загрузке)**
```bash
insmod rw_db.ko readers=3 writers=2 initial_count=50
```
- `readers` — количество потоков-читателей (по умолчанию 2).
- `writers` — количество потоков-писателей (по умолчанию 2).
- `initial_count` — сколько записей создать при старте (по умолчанию 42).
